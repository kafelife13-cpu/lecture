# 한글 제작 PC 연결

오답연구소에서 학생을 선택해 만든 비공개 제작 요청을 Windows의 한컴 한글로 처리합니다. 웹앱은 다른 컴퓨터에서도 열 수 있지만 HWP 제작 중에는 이 연결 프로그램과 한글이 설치된 PC가 실행 중이어야 합니다. 서버만으로 HWP가 만들어진다고 표시하지 않습니다.

1. Windows에 한컴 한글, 같은 글꼴, Python 3를 준비합니다. Python 패키지는 `pywin32`, `lxml`, `Pillow`가 필요합니다.
2. `config.example.json`을 이 폴더의 `config.json`으로 복사해 프로젝트 주소와 공개용 키, 비공개 원본 자료와 서식 위치를 설정합니다. 서비스 역할 키는 사용하지 않습니다. 상대 경로는 이 폴더 기준입니다.
3. 기존 원본 은행의 `inventory.json`, 원본 HWP 및 `hml` 폴더를 `bank`에 둡니다. 서로국어 기준 `template.hml`을 `template`에 둡니다. 원본 자료·학생 파일·설정은 Git에 올리지 않습니다.
4. `python cloud/desktop-worker.py`를 실행하고 기존 김까까 교사 계정으로 로그인합니다. 비밀번호는 저장하지 않습니다. 한글 병합은 한 PC에서 하나씩 처리합니다.

완료한 HWP·HWPX·PDF는 기존 프로젝트의 비공개 저장소에 올라가며 학생에게 자동 공개되지 않습니다. 원문 본문·실제 미주·그림의 내용과 순서를 검사하고 원본 파일 해시를 재확인합니다. 지면은 교사가 배부 전에 확인해야 합니다.

PDF만 있는 문항은 원본 표·옛한글·보기·선지를 지면 이미지로 보존합니다. 이미지 내부의 모든 글자를 편집 가능한 문자로 변환했다고 표시하지 않습니다. 원본과 김까까 정답이 다르면 교사 정정 기록과 등록 정답을 유지하고 차이를 자료에 표시합니다.

자료에 없는 고난도 문항을 새로 만들어 수를 채우지 않습니다. 검수된 후보가 부족하면 부족 수를 그대로 표시합니다.
