# 문학모의고사 상세 해설 교정 기록

2026-09-08: 원본 PDF 94–128쪽, 35쪽을 이미지와 대조해 전수 교정했다. 10회 170문항의 정답 풀이와 오답 풀이, 40개 지문 묶음의 작품 해제·특징·주제를 회차별 자료에 연결했다. 6회 15번·17번은 원본에 별도의 오답 풀이가 없다.

이 폴더의 094.txt–128.txt는 원본 두 단의 읽기 순서를 보존한 대조 기록이다. 원본의 줄바꿈은 유지했다. `assets/literature/detail-review.json`의 SHA-256 값과 자동 대조한다. 원본 문제·지문의 옛한글은 같은 교재의 학생용/교사용 PDF 글꼴을 복원한 텍스트로 추가 대조했다. 정답 170개와 배점은 변경하지 않았다.

## 도구와 검증

- 한국어 재인식: [PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR), Korean PP-OCRv5 mobile recognition. OCR 출력만으로 확정하지 않고 원본 이미지와 대조했다.
- PDF 처리 참고: [Anthropic PDF skill](https://github.com/anthropics/skills/blob/main/skills/pdf/SKILL.md).
- 옛한글 표시: 저장소의 Noto Sans Old Hangul 글꼴, Unicode 조합 자모. 교정 PDF를 렌더링하여 표시를 확인했다.
- `node scripts/check-literature.cjs`: 170개 정답, 선택지, 배점, 실제 답안 채점 및 저장 실패 처리, 오답노트, 요일 분류.
- `node scripts/check-literature-study.cjs` 및 `check-literature-study-flow.cjs`: 시작·일시정지·재개, 실제 학습시간, 중복 저장과 저장 실패 복구, 새로고침, 30분 제한.
- `node scripts/check-literature-details.cjs`: 35쪽 대조 기록, 170개 상세 해설, 40개 작품 묶음, 고어·한자·기호, 학생 및 교사 화면의 상세 해설 렌더링.

GitHub Actions `Literature grading and text checks`에서 위 검사를 실행한다. 이 검사는 자료 누락이나 기능 회귀를 잡기 위한 것이며, 문학 해석의 정확성을 자동으로 보증하는 검사는 아니다.
