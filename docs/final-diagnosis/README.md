# 기말고사 대비 학생별 진단 분석지

학생의 중간고사 오답·선택 답·풀이 사진·사고 과정과 클리닉 누적 결과를 연결해 강점·반복 취약점·보완점을 진단하고, 학교 프린트 근거와 학원 문제은행 보강 문항을 붙인 분석지를 만든다.

## 역할 분담

| 담당 | 맡는 일 | 기준 문서 |
| --- | --- | --- |
| Claude | 문항 유형 분류, 오답 원인 분석, 진단 판정 규칙, 보강 문항 선정 기준, 분석지 구성. 판단 기준의 변경·해석은 Claude가 결정한다. | `ANALYSIS_CRITERIA.md`, `taxonomy.json` |
| Codex | 국어왕(김까까) 데이터 연결, 교사용 제작실, 인쇄·앱 배포, 검증. 기준을 코드로 옮기며, 기준에 없는 판단이 필요하면 임의로 정하지 않고 질문으로 남긴다. | `CODEX_WORKORDER.md` |
| 선생님 | 분류 코드 확정, 원인 확인(교사 기록), 상담 질문 확인, 배부 승인 | — |

## 진행 순서

1. 분석 기준과 분류 코드 확정 (이 브랜치)
2. Codex: 고정 분류 코드 저장·입력 화면, 진단 집계 함수, 분석지 초안 생성
3. 학생 1명 분석지 제작 → 선생님 검토 → 기준 수정
4. 전체 학생 확대

## 개인정보 원칙

이 저장소는 공개 저장소다. 학생 이름·성적·답안·사고 과정·시험지와 풀이 사진·문제은행 원문은 커밋하지 않는다. 실제 분석지는 기존 비공개 Supabase 테이블(`odap_packets`)과 비공개 Storage에만 저장한다. 예시와 테스트는 합성 학생(`학생A`)과 가상 문항만 쓴다. `tools/odap/data`, `bank`, `config.json`은 이미 `.gitignore` 대상이다.
