# 주간 피드백 API 연결

기존 국어왕 교사 로그인과 배포된 `claude-ai` 함수를 재사용한다. 새 API 키를 브라우저에 넣지 않는다. `odap/index.html`의 주간 피드백 메뉴에서 저장된 학생 과제를 선택한 뒤 근거·빈칸 확인 또는 OX 20문항 생성을 누른다.

- `/api/weekly-feedback/context`: 기존 `odap_homework get`로 학생 소유 과제를 읽고, 현재 승인 근거/원본 학교를 다시 대조한다. 저장 당시와 quote/statement/concept/page가 달라진 근거를 제외한다. 학교 프린트의 실제 인용문 quote 안에 정확히 한 번 있는 blank_answer를 우선 빈칸으로 변환한다. blank_answer가 비어 있을 때만 승인 근거의 concept이 quote에 정확히 한 번 등장하는지 확인해 후보로 쓴다. 둘 다 해당하지 않으면 빈칸을 만들지 않는다. 명제 statement에만 있는 단어나 추측한 개념으로 원문 빈칸을 만들지 않는다. 결과의 blank_basis로 등록 정답과 정확한 개념 일치 후보를 구분하며 둘 다 pending이다.
- `/api/weekly-feedback/ox`: 같은 검사를 반복한 뒤 기존 `/functions/v1/claude-ai`에 1~5개씩 요청한다. UI는 최대 4회 순차 실행하여 20문항 초안을 구성한다. 실패한 묶음은 추가하지 않고 앞서 성공한 문항을 탭 메모리에 유지한다. 다시 생성·이어하기를 눌러 부족분만 요청한다.
- `/api/weekly-feedback/variant`: 기존 `variant_context`가 승인한 원문과 연결 근거로 변형 문항을 요청한다. `{question_id,evidence_id,student_id}`를 받으며 저장 없이 pending 문항을 반환한다. 별도 변형 선택 UI는 아직 추가하지 않았다.

API 요청은 교사 자격을 기존 서버에 보내지만 AI payload에는 근거·원문과 기존 생성 문항 텍스트만 들어간다. 학생 이름·성적·답안 기록을 직렬화하지 않는다. 모델 응답은 JSON/근거 id/정답/해설/중복/선택지 수를 검사하며 잘린 응답은 거부한다. 정답의 교육적 타당성은 교사 검수가 필요하다.

생성 결과는 모두 `pending`, `scope_review_required:true`다. 학교 범위·작년 기출 포함 여부·문항 내용 검수와 별도 Drive 저장이 끝나기 전에는 학생 배부 불가다. 현 단계에서는 탭 내 보존과 비공개 로컬 JSON 내보내기를 지원한다. 기존 `save_ox`는 최대 10문항이고 큰 본문 DB 저장을 하므로 이 연결에서 호출하지 않는다. 탭을 닫으면 메모리 초안은 사라진다.

요청에는 월요일 `week_start`를 지정한다. UI 기본값은 한국 시간 기준 이번 주 월요일이며 학생 과제+주차별로 메모리 초안을 분리한다. 기존 odap_sources 스키마에는 연도·시험범위 필드가 없다. 따라서 제목에 2025가 있어도 작년 기출이라고 자동 확정하지 않는다. context/OX 응답의 coverage는 필요한 기출 연도를 `week_start` 연도-1로 계산하되 `past_exam_year_verified:false`, `scope_verified:false`를 유지한다. 허용 근거 종류는 학교 프린트·학교 기출·내신 기출이며 교사 필기·모의고사 등은 이 주간 OX 경로에서 제외한다. 원본 연도/범위 검수 메타데이터가 추가되기 전까지 20문항을 생성해도 ‘배부 완료’가 아니다.

검증: tests/weekly-feedback-api.cjs가 현재 승인 상태, 원문 변경, 학생 정보 제외, 초안 상태, AI 오류/형식/중복 검증, 기존 인증 경로 연결, DB 쓰기 없음, 스크립트 순서를 확인한다. 실제 서버의 무인증 401은 인증 차단을 확인한 것이며 실제 교사 로그인 후 AI 생성 성공을 확인한 것은 아니다. 배포 후 교사가 로그인하여 실제 승인 근거로 5문항 생성·내보내기를 먼저 확인해야 한다.
